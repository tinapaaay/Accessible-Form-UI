# Accessible Form UI

A static and accessible sign-up form built with HTML and CSS.

This project includes fields for a full name, email address, password, and confirm password. It also includes a password-requirements checklist, a completeness progress bar that starts at 0%, and accessible form features.

## Features

- Full name, email, password, and confirm-password fields
- Connected `<label>` elements for every input
- Keyboard-visible focus states
- Accessible password toggle buttons
- Empty error-message areas associated with each input
- Progress bar with ARIA attributes
- Password requirements checklist
- Responsive form layout

## Built With

- HTML5
- CSS3

## Accessibility Practices

- Semantic form controls
- Clear input labels using `for` and `id`
- `aria-required` for required fields
- `aria-describedby` for helper and error messages
- `aria-live` error-message containers
- Clear focus outlines for keyboard navigation
- High-contrast text and buttons

## Note

This is currently a static UI. The password visibility buttons, validation messages, checklist, and progress bar can be made functional later with JavaScript.
